# {{name}}

A [PVOS](https://github.com/christcb03/pvos-sdk) app.

```bash
pvos-dev run       # build it and run it in a throwaway PVOS
pvos-dev test      # its end-to-end test, against the real PVOS
pvos-dev package   # the folder `pvos install` takes
```

On a Mac or on Windows, open this folder in its dev container: the dev kit's
programs are Linux x86-64.
